# AutoToggle

A lightweight, fully client-side mod that adds one-key toggles for running, sneaking, jumping, clicking, tool switching, and elytra fireworks.

## ✨ Features

| Feature | Default Key | What it does                                                                |
|---|---|-----------------------------------------------------------------------------|
| **Auto-Run** | `R` | Toggles running on/off                                                      |
| **Auto-Shift** | `Y` | Toggles sneaking/shifting on/off                                            |
| **Auto-Jump** | Unbound | Keeps the character hopping while enabled                                   |
| **Auto-Left-Click** | `I` | Auto-breaks blocks or attacks mobs, respecting sword attack cooldown |
| **Auto-Right-Click** | Unbound | Auto-places blocks or fires charged bows/crossbows                          |
| **Auto-Tool** | `K` | Auto-selects the best hotbar tool for the block you're mining               |
| **Auto-Firework** | Unbound | Auto-launches fireworks while gliding with an elytra                        |

All keybinds are fully remappable in **Options > Controls**.

### Also included
- **Sneak without stopping** — hold Shift to sneak while autorunning keeps you moving
- **Steer with A/D** — curve left and right without interrupting autorun
- **Riding support** — works on horses, boats, and other vehicles
- **Clean feedback** — toggling plays a click sound and shows an on-screen message
- **Multi-language** — fully localized into every language in the game (129 languages)

## ⚠️ Fair Play

AutoToggle automates repetitive inputs — Auto-Left-Click can break blocks or attack mobs at full weapon cooldown, Auto-Right-Click places/fires continuously, Auto-Tool switches tools while mining, and Auto-Firework launches rockets while gliding.

Some servers consider this an unfair advantage and may prohibit it. **Use these toggles at your own risk** — we are not responsible for any bans, restrictions, or other consequences resulting from using this mod on public servers. Check your server's rules before enabling them.
